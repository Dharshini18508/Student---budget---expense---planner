# Student Budget & Expense Planner

## 📌 About the Project

Student Budget & Expense Planner is a simple web application
designed to help students manage their monthly income and expenses.

## ✨ Features

- 💰 Monthly income / allowance management
- 🍔 Food expense tracking
- 🚌 Travel expense tracking
- 🏠 Hostel / Rent expense tracking
- 📚 Education expense tracking
- 🎮 Entertainment expense tracking
- 🛍️ Shopping expense tracking
- 💊 Health expense tracking
- 📦 Other expenses
- 📊 Total expense calculation
- 💵 Remaining balance calculation
- 📈 Financial status
- 📱 Mobile-friendly design

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- GitHub Pages

## 🚀 How to Use

1. Enter your monthly income.
2. Enter the expected expenses for each category.
3. Click the "Calculate Budget" button.
4. View your total expenses.
5. Check your remaining balance.
6. Check your financial status.

## 🎯 Purpose

The main purpose of this project is to help students
plan their monthly budget and control unnecessary expenses.
